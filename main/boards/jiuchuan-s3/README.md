# jiuchuan-xiaozhi-sound
Jiuchuan Xiaozhi AI Speaker

## Build Guide
**Development environment**: ESP-IDF v5.4.1

### Build Steps:
> **Tip**: If online component fetch fails during build, try toggling your network accelerator or switch to a domestic mirror in [idf_component.yml].

1. Open the project folder in VSCode;
2. Clean the project;
3. Set ESP-IDF version to `v5.4.1`;
4. Click the VSCode prompt to generate [compile_commands.json];
5. Set target device to `[esp32s3] -> [JTAG]`;
6. Open **SDK Configuration Editor**;
7. Set **Board Type** to **Jiuchuan**;
8. Save configuration and build.

## Flashing Steps
1. Connect the speaker to your PC with a USB cable;
2. Power off the device, then press and hold the power button;
3. Select the correct serial port in the flash tool;
4. Click flash and choose UART mode;
5. Do not release the power button until flashing completes.


## Pinout
- 1-9：
  - 1. DAT2     ： NC
  - 2. CD/DAT3: Chip select, active low (unknown)
  - 3. CMD: IO48 (Command/Response line); host sends commands and data to the TF card on this line
  - 4. VDD: Power supply
  - 5. CLK: IO47 (clock), generated by the host to synchronize data transfer
  - 6. VSS      ： GND
  - 7. DAT0: IO21, SPI_MISO; TF card returns responses and data to the host on this line
  - 8. DAT1     ： NC


  Pins are numbered 1-9 from right to left
